# 当前安装器素材来源

奔跑小羊使用 `docs/installer-animation/video-run/frames/` 中的 24 张透明 PNG，直接提取自用户提供的 `豆包 (2).mp4`。每张原样复制进入构建目录，无重绘、拆分、单帧居中或额外跳动，播放周期为 1 秒。

地球来自指定素材目录 b.png，固定圆心与外圈，内部单独旋转。边缘处理只给移动内层延伸边缘颜色，原画外轮廓仍由固定图层保留。云层、品牌及完成姿态来自 d/e.png，云层轮廓遮罩用于去除拍在效果图中的天空和地球，保留原色。左上角软件图标按用户授权来自项目 icon.png。

旧 `sheep-run-sheet.png` 已停用并删除，可从修改前的 Git 检查点恢复，不进入新预览。素材处理来源与哈希会写入构建目录 provenance.json。
