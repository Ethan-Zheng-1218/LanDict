# 翻译页字号与间距预览（原布局修正版）

目标：以用户提供的 miracle 实机截图和当前 `/query?q=miracle` 页面为基线，只调整字号与间距，保留既有布局。

## 修正范围

- 删除先前擅自添加的顶部“翻译”栏、窗口控制装饰和预览工具栏。
- 恢复首页、翻译、阅读、生词本、背单词五项导航，侧栏保持 184px。
- 搜索框保持 56px 高、900px 最大内容宽度和原有位置，保留右侧释义提示。
- 使用原来的“词库解释 / 有道词典”标题，保留词性在释义上方、例句的 72px 空列与 16px 间距、搭配在例句下方、词形变化在最后的结构。
- 字体仍为本地 Noto Sans SC，保持原来的颜色、图标、字重、圆角和左对齐关系。没有分栏，没有把词性并入释义行。
- 紧凑版仅覆盖查询页面字号和纵向间距：单词 40 → 30px，释义 20 → 16px，词典标题 20 → 16px，例句 16 → 14px / 1.65，卡片内边距 24 → 16px；主布局、导航、搜索尺寸不变。
- 默认使用截图中的 miracle，包含相同的两组释义、三条双语例句、四条搭配和复数。保留当前真实 DOM 中的空释义组，避免原版比较时平白少掉 8px。

## 预览与复现

直接打开 `translation-compact-preview.html` 为紧凑版；加 `?state=original` 查看同一布局下的原版尺寸。比较通过 URL 完成，不往应用顶部添加控件。

HTML 内嵌本地 Vite 实际编译的应用 CSS，由 `render-translation-preview.mjs` 生成；使用项目原有 Lucide 图标。需要重新同步样式时，先启动本地 Vite，再运行 `node design-previews/render-translation-preview.mjs`。这是生成静态预览，不是生产构建或安装包流程。

只用于 miracle 的静态设计预览：收藏是当前页临时状态，折叠可操作，语音使用浏览器系统朗读；侧栏不切换页面，搜索不接词典，AI 区域只保留原来的收起外观。本次没有修改应用源码。

## 审核方法

上一版只审核了预览自身的显示和滚动，没有与真实界面的结构核对，因此不能作为布局一致性的证据。之前的分栏方案和 approach 高度统计作废。

本次先核对 `AppFrame.tsx`、`QueryPage.tsx`、`DictionaryPanel.tsx` 和实际页面 DOM，再比较原版预览与真实页面的侧栏、搜索框、单词标题、词典卡片及例句位置。截图中的系统标题栏属于 Windows，浏览器 HTML 不额外仿造标题栏；对比内容视口为 1180×760。

- 浏览器核对：原版预览与真实应用均为 184px 侧栏、900×56px 搜索框、52px 高的 40px 单词标题、729px 高的词典卡片。两者搜索框顶部均为 28px、卡片顶部均为 212px、第一条例句顶部均为 499px；横坐标按居中内容的起点比较，真实页面与预览可用视口宽度不同。
- 1180×760 的紧凑版已实际看图：五项导航完整，没有顶部标题栏或预览工具栏；词性、例句、搭配仍然纵向排列，没有横向溢出。卡片高度为 602px。保留全部内容后仍允许自然滚动，不再宣称一屏容纳全部词条。
- 已实际操作词典收起与展开，展开后内容恢复；浏览器错误日志为空。未做独立评审，未做系统语音听感验证。当前浏览器预览已保持打开。
- 只改静态 HTML、生成脚本和本说明；未改应用源码，未运行应用全量测试或安装包构建。
