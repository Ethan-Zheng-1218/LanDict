# LanDict 生词本 V4 预览说明（三档状态 + 导入）

V4 在 V3（`LanDict_生词本_交互设计稿_V3.html`）基础上只做两件事：把学习状态从四档压成三档、
把导入做成可用可看的界面。其余视觉、布局、遮挡模式、排序、撤销提示条与前作一致。

## 一、三档学习状态

- 状态集合：`待学习 / 学习中 / 已掌握`，删掉原来的"未加入"。
- 配色：待学习红、学习中橙、已掌握绿。语义是"离学会还有多远"，红 → 橙 → 绿自带前进感。
- 三个颜色都用"浅底 + 深字"的标签，不用实心色块：待学习是绝大多数词的默认状态，
  实心红铺满整列会让红色失去信号作用。
- 学习中用偏黄的橙（`--orange:#c1701a`），不用偏红的橙：红橙相邻时两块颜色容易糊在一起，
  对色觉障碍读者更明显。三色都走主题变量，暗色主题下自动变成浅粉 / 浅橙 / 浅绿。
- 收藏进来的词默认就是"待学习"，因为能进生词本的词按定义就是要学的。
- 顶部计数从"共 11 个单词"改成"共 11 个单词 · 待学习 6"，一眼能看到还有多少没开始。
- 右栏原来的主按钮"全部加入学习"在三档模型下失去意义（所有词都已在学习队列里），
  改为"开始背单词"——指向下一篇要设计的背单词页面。这是本轮唯一一处需要确认的取舍；
  若想保留批量操作，可改成"全部开始学习"（待学习 → 学习中）。

## 二、导入（最小方案）

入口：右栏工具条"导入"，打开弹窗。弹窗只有四块：

1. 一行说明：粘贴插件导出的 JSON，或者一行一个单词；重复跳过；没释义先记"待补充释义"。
2. 粘贴框（主入口），占位符里同时给了 JSON 和纯文本两种示例。
3. 文件入口（次入口）：`.json / .txt / .csv`，也可拖进去；CSV 按 UTF-8 与 GBK 解码。
4. 一行结果 + 一个按钮：`识别到 12 行：新增 9 个，重复跳过 2 个，1 个待补充释义` → `导入 9 个词`。

导入的词：状态 = 待学习，来源 = 导入，词性 / 搭配 / 例句留空，打开词条时由本地词典补上。
重复判断按小写单词做，已存在的词直接跳过，不覆盖用户已有的释义。
示例按钮、词条预览条、文件大小提示这些演示零件都去掉了。

## 三、这一版没有做的事

- 不做磁盘写入；demo 里只读浏览器里选中的那个文件。
- 没有 Excel `.xlsx`、Anki `.apkg`、PDF、图片导入。
- 没有改主题相关的东西：主题仍然只在设置页，侧栏不出现主题卡片（沿用 V3 的删减状态）。
- 没有背单词页面本身，只有一个入口按钮。

## 四、图标协议

- 筛选：三根横线，从上到下依次 16 / 10 / 4 长，居中。原来的三根线加三个 1.4px 小圆点，
  在 16px 的图标里会糊成墨点。
- 导入：`#ic-download`（向下箭头 + 托盘，表示收进来）；`#ic-upload`（向上箭头）留给将来的导出。

## 五、文件

- `design-previews/vocabulary-v4-preview.html`：可双击打开的单文件预览，带演示词条，数据存在 localStorage。
- 打开后先看：列表里的状态标签、顶部"待学习 N"、右栏"开始背单词"、以及"导入"弹窗的粘贴和预览。
