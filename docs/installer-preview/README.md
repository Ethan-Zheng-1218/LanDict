当前交付是运行真实 NSIS 文件解压的 Windows EXE 预览，尚未接入正式 Tauri 产品安装模板。软件主体 UI、业务代码和学习数据目录没有改动；没有执行 git push。

## 运行与查看

EXE：`C:/Users/Ethan/Desktop/floders/vibe/Pudict/src-tauri/target/installer-preview/LanDict-native-preview.exe`。

双击直接解压三份真实词典到项目内 `src-tauri/target/installer-preview/extracted/`，完成后显示 100%。没有注册产品、创建快捷方式或安装卸载程序。关闭后可以重复运行预览。

可选参数：`/HOLD` 暂停在 0% 查看动画，点击画面后按 Enter 开始解压；`/TESTFAILURE` 对已有文件创建子路径，制造真实写入失败；`/SCALE=125`、`150`、`200` 仅模拟对应物理尺寸，实际显示 DPI 单独记录；`/RECORD` 保存约三秒本窗口实际绘制缓冲区，按真实时间导出视频，不生成安装进度。

正常/完成/失败截图分别为 `running-100.png`、`success-100.png`、`failure-100.png`。`native-window.mp4` / `.gif` 来自原生窗口绘制记录，展示暂停在 0% 时的动画，不是 HTML 演示。原始捕获时间见 `recording.json`。

## 本轮修改

- 奔跑小羊使用用户视频提取的 24 张完整透明 PNG，1 秒循环。文件原样复制，固定比例和锚点；没有重新绘制或拆分四肢。
- 奔跑整体下移 5 个逻辑像素，并增加淡色柔边接触阴影；完成姿态按用户后续指示继续下移 10 像素，当前位置 y=259。完成图只清除裁片带入的蓝色底色与后方灰色残片，不改角色颜色。
- 地球固定圆心和外轮廓，内部独立旋转；删除固定图层中的内伸海岸残片，不再将静态大陆画在移动内层下面。场景底部裁剪独立生效。
- 用户另行授权重新设计进度条：淡蓝底槽、细浅边框，填充纹理直接取自 b.png 的海洋。云层底部以连续柔和渐变接入进度区，排除效果图中已有进度条的像素。双轴镜像取样与单次渐变绘制消除非整数尺寸下的接缝。
- 图片按窗口大小缓存，计时器只驱动画面；真实 NSIS progress 控件是唯一百分比来源。仅引擎成功完成事件显示 100%。修复中止状态使用错误关闭指令导致窗口无法退出的问题。

## 已核实与未核实

已运行四项 Rust 模型测试，覆盖 24 帧边界、1 秒循环、旋转位移、真实进度与成功后才允许 100%。真实解压的三份文件 SHA-256 均与源文件一致；成功关闭退出码 0，故意写入失败后显示 93% 且退出码 1。主动关闭暂停预览出现销毁记录，没有成功事件。

已检查当前系统 DPI 96（100%）实窗，以及 125% 尺寸模拟。150% 和 200% 完整原生绘制缓冲区分别为 1095×875、1460×1166，见 `size-150-render.png`、`size-200-render.png`；这些不是实际系统显示缩放测试。最后的屏幕验证被桌面上另一个应用的 Armoury Crate 安装/UAC 提示遮挡，待用户自行处理后补齐。没有操作该提示。

`verification.json` 保存素材一致性、灰线透明检查、固定海岸残片检查、解压哈希、成功/失败日志和缓冲区边缘检查。200% 缓冲区的云层渐变终点相邻行最大差异为 4 个色阶，场景裁剪以下保持静止。文件检查不代表用户已经认可审美。

尚未进行正式产品安装、启动、快捷方式、重复安装和卸载测试，也未完成隔离 Windows 环境验证。按用户要求先进行整体视觉确认，再进入正式安装包阶段。

## 复现与维护

`tools/installer/build-preview.ps1` 用 i686 Rust/MSVC 和官方 NSIS 3.11 编译；先运行素材准备并验证全部必需文件，再打包。`prepare-assets.ps1` 的 SourceDirectory 可指向用户提供的 a–e.png 文件夹，图标读取项目 icon.png。独立模块没有加入应用依赖。

`export-recording.py` 使用 PyAV/Pillow，按原生 BMP 文件名记录的时间编码，H.264 仅为偶数尺寸在底部补 1 像素，不插帧、不改进度。`verify-preview.py` 检查真实素材与记录。录屏读取已移出 DC 的位图为独立像素副本，遵循 [GetDIBits 的 API 前提](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-getdibits)。普通运行不写录屏帧。

本轮独立代码审查已核对 NSIS ABI、素材哈希、内存释放和完成状态；录制 API 问题已修复。后续进度条与接缝改动由主执行者在原生画面和缓冲区中自检，尚未完成独立视觉验收。
