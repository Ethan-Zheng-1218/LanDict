## 选择的路线

沿用 Tauri 的 NSIS 安装 EXE，通过独立安装配置和自定义模板设置界面。保留产品标识符、现有应用行为和词典资源映射，不因安装界面动画修改应用框架。

备选是保持默认 NSIS 向导，只替换图片和颜色，工程量少但无法接近视频中间的动画场景。另一条是额外构建 WebView 安装前端，动画播放方便，但需处理前端自身尚未安装时的运行环境以及与安装引擎通信。当前优先采用已有 NSIS 引擎与原生界面，复用标准文件安装、快捷方式和卸载行为。

官方依据：[Tauri Windows 安装器、自定义模板与安装钩子](https://v2.tauri.app/distribute/windows-installer/)。

## 动画实现与进度

新预览使用 Canvas 组合用户上传的地球原图和六张小羊图：整张地球在画面平面内旋转，取消经纬度球面纹理投影；顶部地面向左运动配合小羊朝右奔跑。对齐脚底，添加随落脚和腾空变化的浅灰蓝阴影，云层独立。原生 NSIS 页面不能据此假定能直接播放 APNG/WebM；实际实现优先将现有羊、地球和云层合成不含文字、进度和按钮的场景动画，再使用标准 Windows 动画控件播放兼容的静音 AVI。成功画面使用现有素材合成静态场景。统一画布和缩放；当前完整地球原图没有旧视频提取造成的角色遮挡缺口。

Windows 动画控件接受未压缩或 RLE8 AVI，必须无音轨；使用现代公共控件时还必须验证安装 UI 没有被词典解压阻塞。编写正式模板前先做最小原生播放检查，随后用实际大词典验证安装期间连续播放。该原生播放能力目前尚未实测，网页预览通过不能替代这项检查。

进度使用 NSIS 安装过程提供的进度控件或消息。将真实控件保留在自定义布局中，避免按计时器自行累加百分比。没有可靠字节百分比的准备/收尾阶段显示明确状态；只有成功完成安装、资源放置和快捷方式创建之后才进入成功页。

依据：[NSIS 自定义控件](https://nsis.sourceforge.io/Docs/nsDialogs/Readme.html)、[Windows 动画控件及格式限制](https://learn.microsoft.com/en-us/windows/win32/controls/animation-control-overview)。

## 预计修改与交付

在 src-tauri/windows 下加入安装模板、界面脚本和从既有素材生成场景资源的过程，加入独立安装配置覆盖文件与构建入口。保留默认配置中的词典资源与产品信息。生成的中间动画/场景不作为最终用户学习数据安装；不把参考截图、重复动画格式或调试符号无差别打包。

沿用项目现有 WebView2 检测/补装策略：程序和词典在包内；缺少 WebView2 的机器可能需要联网补装。若要首次安装也完全离线，需要另外选择离线运行环境包，本预览不默认增加该包。

最终交付本地 Git commit、可重复构建的配置和脚本、LanDict 安装 EXE、中文构建说明与验证结果。安装包压缩后的实际大小由构建结果确认，以当前三份词典及 release 构建结果为准。
