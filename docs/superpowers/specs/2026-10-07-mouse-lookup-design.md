# Windows 鼠标取词设计

用户已认可方案并要求开始执行。目标是在其他应用阅读英文时，鼠标停留即可查看单词、中文释义和本句中的 AI 语境义。

## 行为

- Windows 桌面启动后启用取词；关闭主窗口隐藏到托盘，托盘可打开主窗口、暂停/恢复取词、退出。正常、暂停和启动失败状态应准确显示。
- 设置增加鼠标取词开关、停留时间（默认 500ms，100–3000ms）和本地 OCR 补充开关（默认开启）；修改立即生效并持久保存。
- 指针连续停留达到设定时间后读取单词；按 Esc、暂停、关闭按钮或点击窗口外部时隐藏卡片并使旧结果失效。移动到悬浮窗内部时保持显示，停止替换词条；移动到其他词后仍可停留取新词。关闭后须移动鼠标才重新触发。
- 独立无系统边框、不占任务栏的悬浮窗，位于鼠标右下角，跨屏幕边缘自动调整。宽度按单词的实际文字宽度调整（228–480 逻辑像素），高度按内容调整（180–360），超过上限可滚动阅读。使用圆角、细边框和柔和阴影，按屏幕缩放处理。
- 自动显示时不抢焦点，用户按下鼠标操作卡片后才激活。支持选择文字、复制完整内容、关闭和英式发音（优先英式录音，缺少录音时使用 en-GB 系统语音）。右上角关闭按钮，喇叭位于单词右侧。
- 卡片只显示单词、中文释义、AI 语境义。释义与 AI 独立加载；读不到句子时提示“未获取到当前句子”；AI 未配置或失败不影响中文释义。词句仅在启用语境查询时发给用户已有的 AI 服务。

## 实现

Rust 独立工作线程读取 Windows 指针位置，停留后用 UI Automation 的 TextPattern/RangeFromPoint 获取词和附近文本，并验证文字矩形确实覆盖指针。没有可读取文字时使用 Windows 本地英文 OCR 识别指针周围约 1000×240 像素区域，按词矩形定位目标，使用该行及邻近行作为有限上下文。排除本程序、密码控件；取词不修改剪贴板或目标应用选区，只有用户点击“复制内容”后才写入剪贴板。OCR 依赖系统英文识别语言支持，不支持的内容不弹出错误单词。

原生状态保存取词设置、最新样本及递增编号。前端悬浮窗监听样本/清除事件，注册后主动读取最新状态，避免初始化事件丢失；查询结果按编号隔离。主窗口负责与保存的设置同步。

Tauri 托盘和关闭事件在 Rust 中管理。打包 ECDICT SQLite 文件并提供原生查询命令（保留词形回退），桌面 AI 请求走原生 HTTP，解除对开发服务器和 WebView CORS 的依赖。Web 版保留现有请求路径，仅显示桌面功能说明。

## 验证与范围

测试设置迁移/延迟校验、悬浮窗加载/无上下文/旧结果隔离、指针停留/重置/屏幕定位、词形查询和桌面请求通道。涉及共享设置与查询层，提交前运行全量 Vitest、前端构建和 Rust 测试/构建。

使用浏览器、文本编辑器进行原生取词验证（运行环境可用时）；自动测试不能代替跨应用验证。首版支持 Windows，不增加开机启动、浏览器扩展、查词历史记录或生词操作。

## 交互优化与设置整理

依据用户截图及新需求，增加窗口尺寸测量、原生外部点击监听、关闭后的重弹抑制、复制和英式发音。Logo 取消主题滤镜并保持原图颜色；删除“默认语言”栏；“单词自动查询”和“AI 自动翻译”移到翻译页 API 配置上方，保留原有设置数据。

原生托盘和窗口图标将与外缘连通的近白底色变透明，内部书页与原始颜色保留。最终交付 exe，不制作安装器。
