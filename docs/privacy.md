# 隐私与数据

本文根据 0.1.11 的实现整理，帮助了解数据存放位置与联网行为。

## 保存在本机的内容

生词、笔记、学习状态、复习进度、查询历史、阅读记录及应用设置主要通过应用 WebView 的本地存储保存。目前无需注册登录，没有云端学习数据同步。

生词本支持导出 JSON 备份，备份可能含个人词条和笔记，分享前请自行检查。它不包含所有应用数据。

## API Key

AI API Key 保存在本机应用设置中。当前实现使用本地存储，未接入独立的加密凭据库；输入框隐藏字符不等于加密保存。不要共享应用数据目录、包含密钥的截图或配置。需要撤销访问时，应在服务商后台停用对应密钥。

## 哪些操作会联网

- **联网词典**：查询内容会发往有道等相应词典服务。
- **阅读内容**：刷新及打开文章会访问内容来源或其资源地址。
- **发音**：部分词条使用在线音频；可用时也会尝试系统朗读。
- **AI**：待翻译文本、目标单词及相关请求内容会发送到你设置的 AI 接口；请求使用该接口的 API Key。
- **本地翻译资源准备**：首次准备或修复资源时，会从 Python 官方站点、PyPI 和 Argos 模型站点下载运行环境、依赖及模型；资源就绪后的本地翻译在本机执行。
- **安装依赖**：缺少 WebView2 时，安装过程可能需要联网获取组件。

第三方服务的可用性、使用条款、数据处理和费用由对应服务商决定。请勿把不愿提供给外部服务的内容发送给联网词典或 AI。

## 鼠标取词与 OCR

开启桌面取词后，应用尝试读取鼠标附近文字；启用 OCR 时可进一步在本机识别附近英文。识别出的词语随后可能进入联网查词流程。可在设置中关闭鼠标取词或 OCR。

## 备份与反馈

卸载或迁移前请主动导出生词备份。反馈问题时，建议仅提供重现所需的最少资料，并遮盖 API Key、私人文本及系统个人信息。

模型及运行环境的第三方声明见 [NOTICE](../tools/local-translation/NOTICE.md)。
