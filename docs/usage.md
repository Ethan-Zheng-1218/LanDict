# 使用指南

## 查词与翻译

在首页输入英文单词、短语、句子或中文，按 Enter 查询。联网时词条优先使用有道，本地词库提供离线查询和回退。整句查询使用本地翻译与可选 AI，不提供有道整句译文。

输入英文时可显示简短释义及灰色补全建议：Tab 接受补全，Esc 隐藏建议。释义、例句和译文中的英文单词可点击继续查询。查询历史可以再次打开。

本地中英翻译需要先完成运行环境和模型下载。初次启动提示资源准备中时，稍后重试即可。

## 可选 AI

在设置中选择 DeepSeek、OpenAI 或自定义 OpenAI 兼容接口，填写相应的服务地址、模型和 API Key，再测试连接。可以手动展开 AI 内容，也可以开启自动调用。

英文单词提供例句、词根、近义词、反义词和派生词学习入口；短语和文本可使用 AI 翻译。请求会发往所配置的服务商，费用和数据政策由该服务商决定。AI 输出可能有误，学习时应结合词典及上下文判断。

## 英文阅读

进入阅读页浏览推荐、新闻或文章，联网刷新内容。点击正文中的英文单词可查词并加入生词本；同时支持朗读、字号调整、文章收藏与续读。来源网站的可用性会影响内容获取。

## 生词本与备份

从查词页、阅读卡片或桌面取词卡片收藏单词。在生词本中搜索、排序、隐藏释义自测，或调整“待学习／学习中／已掌握”状态。

- **导入**：粘贴词表，或选择 TXT、CSV、JSON 文件；重复词会跳过。
- **导出**：生成完整 JSON 生词备份；桌面版可使用保存对话框选择位置。
- **恢复**：导入 LanDict 的 JSON 备份，恢复生词、笔记、学习状态和收藏时间；不会用重复词覆盖现有内容。

生词备份不包含全部应用设置及独立的背词复习安排，请妥善保管备份文件。

## 背词与间隔复习

选择考试词库、生活高频词或自己的生词本，设置每天的新词量，再进入新学或复习。系统按“认识、不确定、不认识”的判断安排后续复习。

显示单词时：← 不认识，↓ 不确定，→ 认识，↑ 收藏。展开释义后：← 重新作答，↓ 改判为不认识，→ 下一个。空格重复发音，Esc 退出学习。

## 桌面取词与外观

设置中可调整鼠标取词开关、停留时间及 OCR，并切换轻盈绿、慕夜黑或晴空蓝主题。取词依赖目标软件和文字的可读取程度，并不覆盖所有场景。

可按需开启开机自启。关闭主窗口后应用可以继续在托盘运行。
