# 直接提取用户视频中的完整小羊帧

## 来源和选段

源文件：`C:/Users/Ethan/Downloads/豆包 (2).mp4`。本目录 `doubao-reference.mp4` 是原样副本。SHA-256 为 `0578733137522661fa5d3655c36bd7062202a95e9ca1deb5c351744052f2df3d`；不修改原文件。

视频为 720×720、24 fps、241 帧，约 10.04 秒。比较前段连续姿态与约 22–25 帧的重复间隔后，选择 **源帧 14–37（编号从零开始）**：开始于 0.583 秒，最后一帧位于 1.542 秒，循环总长 1 秒。此段包含两次交替的伸展与收回，头部和羊毛较稳定，接回起点的差异较低。保留全部 24 张连续帧，避免降低原视频动作的细腻程度。

没有插入重复帧、倒放帧、人工过渡或 AI 补帧。原视频并非专门制作的无缝动画，因此循环自然程度仍由实际预览审查；图像差异数值只帮助选段。

## 素材处理

- 全部帧统一裁剪源图 `(120,120)–(650,595)`，得到 530×475 RGBA。
- 从棕色蜡笔外轮廓识别完整剪影，闭合小于约 3 像素的压缩缺口，再从画布边缘填充外部区域。这样保留轮廓内部的奶油色羊毛，避免把浅色身体当作白底删掉。
- 只处理透明通道；每张 PNG 的 RGB 与对应源视频裁剪逐像素相同。透明边缘使用 0.6 像素的抗锯齿处理。
- 纸面背景、地面蓝色阴影不进入角色素材；视频角落标识位于角色裁剪范围外。完整源视频保留不变。
- 不拆分四肢，不转动身体部件，不重新画脚，不独立重新居中每一帧。原视频的小幅身体起伏由同一坐标系保留。

## 交付文件

| 文件 | 用途 |
| --- | --- |
| `video-run/frames/frame-00.png` 至 `frame-23.png` | 24 张透明完整角色帧，供原生绘制加载 |
| `video-run/sprite-sheet.png` | 6 列 × 4 行，每格 530×475，透明背景 |
| `video-run/transparent.webp` | 保留透明背景的循环动画 |
| `video-run/preview.gif` | 正常速度循环，24 帧合计 1000ms |
| `video-run/slow.gif` | 三倍慢放，24 帧合计 3000ms |
| `video-run/contact-sheet.png` | 带源帧编号的动作对照 |
| `video-run/manifest.json` | 来源哈希、帧编号、裁剪、时长、检查结果 |

GIF 时间只能按 10ms 记录，所以采用 40/50ms 分配，总周期严格为 1000ms。原生绘制应按 `elapsed_ms % 1000 * 24 / 1000` 选择帧，不按 GIF 的单帧舍入时间驱动。所有帧使用固定绘制矩形，不额外加入身体位移。地球应使用固定圆心的独立旋转，不能随角色外框变化而移动。
