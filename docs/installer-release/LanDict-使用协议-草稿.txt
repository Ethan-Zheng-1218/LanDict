LanDict 软件使用协议
版本：2026-10-08

请在安装前阅读本协议。选择“我已阅读并同意软件使用协议”并开始安装，表示你同意以下使用说明。

一、软件用途
LanDict 提供查词、阅读、朗读和生词学习功能。词典释义、翻译和语音结果供学习参考；不同内容来源可能存在差异或错误。

二、本地数据
查询历史、生词本和软件设置保存在当前设备的用户数据目录中。普通卸载不会主动删除这些学习数据。请自行备份需要长期保留的内容；更换设备、清理系统或主动删除用户数据可能导致内容丢失。

三、联网功能
使用在线文章、在线发音或 AI 翻译时，软件会向相应服务发送完成该功能所需的请求。AI 翻译会使用你配置的服务地址、模型和 API Key，并发送待处理的单词、文本或附近句子。第三方服务的可用性、收费和数据处理规则由该服务提供方决定。请根据需要配置或关闭相关功能。

四、安装选项
开机自启由你选择，默认关闭，安装后可在“设置—通用”中调整。创建桌面快捷方式由你选择，默认开启。保留本地安装包默认开启；取消此选项后，仅在本次安装成功并关闭安装窗口后删除本次运行的安装 EXE。安装失败或取消时保留该 EXE。

五、第三方内容
软件中使用的词典、字体和其他第三方内容，适用其各自的许可和权利说明。本协议不替代第三方许可，也不授予超出相关权利说明的使用权限。

六、选择与退出
你可以在确认本协议前退出安装。安装后可通过 Windows 的应用管理或软件卸载程序移除 LanDict。
