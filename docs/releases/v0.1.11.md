# LanDict 0.1.11

发布日期：2026-11-25。适用于 Windows x64。

下载并运行 **LanDict_0.1.11_x64-setup.exe** 即可安装。安装完成后，在“设置 → 关于”确认版本为 **0.1.11**。

## 本次与近期变化

- 首页标题居中放在搜索框上方。
- 支持选择生词备份保存位置，以及完整 JSON 生词备份与恢复。
- 改善鼠标取词卡片尺寸稳定性，离线翻译资源在启动后后台准备。
- 修复安装器素材查找路径。
- GitHub 仓库补齐安装、使用、开发、隐私和版本说明。

## 安装前了解

- 当前开发环境为 Windows 11，Windows 10 兼容性尚未验证。
- 安装包尚未代码签名，系统可能提示未知发布者；请核对来源和 SHA-256。
- 缺少 WebView2 时，安装可能需要联网；首次使用本地翻译也需要联网下载运行环境及模型。
- AI 需要自行配置服务和 API Key，普通查词无需配置 AI。
- 升级前建议从生词本导出 JSON 备份。
