# 安装选项排版预览

用户要求先以 HTML 调整底部布局，确认后再同步原生安装器。本轮未修改原生排版、软件业务或正式打包流程。修改前本地检查点为 65df2e0，保存了前一阶段尚未完成的安装接入草稿。

双击 `安装选项排版预览.html` 可离线查看，图片、脚本与协议均已内嵌。逻辑画布仍为 730×583；上方使用已确认原生画面的一张静帧，本页没有重新制作角色、地球或云朵动画。

底部第一行由同意复选框、同意文字和紧邻的协议链接组成；第二行按开机自启、保留本地安装包、创建桌面快捷方式的顺序并排。开始安装按钮在右侧，跨两行垂直居中。开机自启和同意默认未选，另外两项默认已选。协议可在对话框阅读；开始按钮仅用于排版反馈，不执行安装或写入系统设置。

页面前部 CSS 变量控制上下位置、左右留白、行距、选项间距及按钮大小，便于按用户后续反馈调整。`?state=ready` 展示勾选同意后的样式，`?state=agreement` 展示协议阅读样式。

已检查默认、同意与协议三个浏览器状态，未发现控制台错误、图片加载失败或横向溢出；另检查 CSS 200% 缩放。`review/` 与 `review-200/` 保存截图和检查记录，`verification.json` 记录上方场景逐像素保持一致（内区最大色差 0）。这不是 Windows DPI 或正式安装验证。本轮局部排版由主执行者看图自检，没有独立视觉评审。

Codex 内置浏览器访问本机预览超时，随后错误页面被浏览器 URL 策略阻止读取；没有绕过该策略。临时预览服务已停止，用户可直接打开独立 HTML 文件。

## 安装流程示范（可完整跑通）

`安装流程演示.html` 是可直接交互的完整流程示范，不依赖网络：勾选“我已阅读并同意”并点“开始安装”，进度推进到 100% 后出现“完成安装”，点击后窗口关闭并显示本次选择的安装选项。页面右上角“放大 2×”用于检查小羊与图标清晰度。

同时处理了用户提出的界面问题：

- 标题栏只保留“最小化”和“关闭”，去掉最大化；两个按钮都有悬停高亮、按下反馈和阴影。
- 进度条位置上移到 `y=512`（原 537），百分比移到 `y=504`，底部留出空间。
- 新增“完成安装”按钮，位置和形状与“开始安装”一致（`x=544, y=530, 126×34`），成功后窗口关闭。
- 小羊帧改用 Lanczos 预缩放（530×475 → 264×237，绘制时再缩到 132 宽），接触阴影从 6 层 56 宽收窄为单层 92 宽椭圆，减轻脚下发虚。
- 进度条纹理改为按原始比例平铺，避免整条拉伸导致的模糊和被误认为“没填满”。

`assets/` 存放示范用素材（35 个 PNG，约 4 MB），`vendor/alpine.min.js` 为本地副本，因此页面可离线直接打开。生成脚本为 `tools/installer/prepare-demo-assets.py`。

已用无头浏览器实测：`prepare / installing / done / result` 四个状态截图在 `flow-review/`，真实点击流程记录在 `flow-run2/`（含开始、中间、结束三帧）。示范中的进度是演示数据，真实安装仍由 NSIS 引擎提供进度。

### 第二轮修正（用户反馈）

- 安装完成后地球仍然转动 —— 现在成功状态会给窗口加上 `finished` 类，`animation-play-state: paused` 冻结地球；实测完成状态前后 5 秒地球区域像素差为 **0**，安装中同一区域差值为 6,803,570（仍在转）。
- 地球边缘越过底部分界线 —— 淡出层从场景裁剪里移出来，覆盖整个窗口宽度，颜色在进度条上方就已收敛为单色，地球的裁切边被完全盖住，不再出现横线。
- 进度条压在蓝白交界处 —— 进度条下移到 `y=508`，完全落在下方浅色面板内（淡出在 `y≈500` 已不透明）；百分比 `y=500`，完成按钮 `y=532`，三者互不重叠。
- 尾巴与手部发虚 —— 24 帧小羊改用 Lanczos 预缩放后再加温和的 unsharp mask（半径 1.1、强度 110），完成姿态 `complete.png` 也做同样锐化。

对应证据：底部区域放大图 `flow-review4/installing-bottom-zoom.png`、`flow-review4/done-bottom-zoom.png`，小羊放大图 `frozen-check-a/complete-sheep-zoom.png` 与 `frozen-check-b/running-sheep-zoom.png`。

### 第三轮修正（用户反馈）

- 完成安装后仍然继续动 —— 去掉了上一轮的冻结逻辑，成功状态也保持小羊奔跑与地球旋转。实测完成状态前后 5.2 秒：小羊区域像素差 986,434、地球区域 6,263,148，两者都在动。
- 取消卧倒姿态 —— 不再使用 `complete.png`，成功界面继续用 24 帧奔跑小羊。
- 100% 进度条没铺满 —— 填充宽度原来按 5.46 px/百分比计算，而轨道内宽是 548px，右端总差 2–3px；改为 5.48 后 100% 正好顶到轨道内边缘（放大图 `v3-done-bar-zoom.png`）。
- 地球边缘始终超出轮廓 —— 原因是旋转内层图案的绘制半径到 420（源图 840 的一半），而棕色蜡笔圈只是 384–420 的模糊圆环，内层边缘会扫到圈外。现在把旋转层裁到半径 47.5%（`clip-path: circle(47.5% ...)`），裁切边落在蜡笔圈实心范围内；圈外区域的帧间变化从 351 个像素降到 211 个，左缘放大图 `v3-spin-a-left.png` 中已经看不到蓝色越出棕线。
