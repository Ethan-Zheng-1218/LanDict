# LanDict 第三阶段：阅读系统 UI

本阶段沿用前两阶段的 Soft Blue 设计系统。一级“推荐 / 频道”使用底线页签；频道内“新闻 / 文章”使用浅蓝分段选择，以体现导航层级。

## 核心文件

- `src/features/reading/ReadingHomePage.tsx`：阅读首页、频道、收藏、历史及继续阅读使用公共组件。
- `src/features/reading/ReadingArticlePage.tsx`：公共图标工具栏、翻译/批注面板、字号与收藏选中状态。
- `src/styles/reading.css`：集中阅读页面样式，900px 列表内容、三/二/一列卡片；正文最大680px、桌面右面板300px。
- `src/styles/app.css`：引入阅读样式，删除已迁移规则及冲突的旧移动端规则。
- 两个阅读页面测试：导航层级/返回选择及批注焦点切换回归。

## 保留与修复

路由、数据提取、新闻接口、查询、翻译、发音、进度和存储格式继续使用现有实现。设置保持左下角，目录保持在侧栏；离线下载入口未恢复。

浏览器验收发现原有批注保存依赖当前正文选区：输入框获取焦点后选区清空，保存失效。新增回归测试先失败，再在打开编辑器时记录原文及偏移，使输入后的保存仍关联原选区，存储格式不变。

样式迁移遗漏的 AI 译文换行已恢复：浏览器固定响应验证先失败、修复后通过。接口使用模拟响应；朗读验证播放/暂停调用，没有调用付费接口或实际播放声音。

## 验证结果

- `pnpm test`：37个测试文件，304项全部通过。
- `pnpm build`：成功。现有 CSS Highlight 识别、设置分包及大包体积警告仍存在，不影响构建。
- 浏览器尺寸：1200×750、900×750、1440×900、680×750、680×500、390×750。
- 未发现页面横向溢出；窄窗口正文与辅助面板上下排列，可滚动访问。
- 通过频道/文章筛选与返回、字号、收藏、朗读/暂停、选词查询、高亮、批注保存及重开恢复、目录跳转、滚动进度与历史入口检查。
- 一次独立只读复核已完成；修复确认的译文分段问题。标签与徽标的间距细节作为次要视觉项记录，未扩大本阶段修改。
