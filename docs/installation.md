# 安装与更新

## 下载

请从 [LanDict 官方 Releases](https://github.com/Ethan-Zheng-1218/LanDict/releases/latest) 下载 Windows x64 安装包。当前版本为 **0.1.11**，文件名为 `LanDict_0.1.11_x64-setup.exe`，大小为 **42,673,243 字节**。

GitHub 自动生成的 Source code ZIP/TAR 是源码，不是可直接运行的 Windows 安装包。

## 校验文件

发布页同时提供 `SHA256SUMS.txt`。在 PowerShell 中运行：

```powershell
Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\LanDict_0.1.11_x64-setup.exe" -Algorithm SHA256
```

将路径改为自己的下载位置。0.1.11 安装包的 SHA-256 应为：

```text
A47C155074CE2DAB1A1F6DED61EC0D7AAD93E8AF33A02325777844BA54171F8A
```

如果结果不一致，请重新从发布页下载并核对。

## 安装

1. 运行安装包，阅读软件使用协议。
2. 选择开机自启、保留本地安装包和桌面快捷方式等选项，然后开始安装。
3. 安装完成后启动 LanDict。
4. 打开“设置 → 关于”，确认显示 **0.1.11**。

安装采用当前用户模式。当前开发环境为 Windows 11 x64，Windows 10 兼容性未验证。应用依赖 Microsoft Edge WebView2；机器缺少该组件时，首次安装可能需要联网。

安装包目前未代码签名，系统可能显示未知发布者或信誉提示。遇到提示时先核对下载来源与哈希；不要关闭系统安全防护。

## 首次使用

首页输入英文单词或中文即可查询，不需要注册账号。首次启动会在后台准备本地翻译运行环境及中英模型，这一步需要联网。提示“离线翻译正在准备”时，可稍后重试。资源就绪后，整句本地翻译可离线使用；联网词典、阅读刷新与 AI 仍需要网络。

## 升级与备份

升级前建议在生词本使用“导出”保存 JSON 备份，再退出正在运行的 LanDict 并运行新版安装包。应用可能仍在系统托盘中运行，可从托盘退出。

JSON 生词备份包含生词、笔记、学习状态和收藏时间，不等同于全部应用设置与背词复习进度的备份。恢复时从生词本“导入”选择备份；重复词会跳过，不覆盖已有词条。

## 常见问题

- **离线翻译一直未就绪**：检查网络能否访问资源下载站点，保持应用运行一段时间后重试；具体联网来源见[隐私与数据](privacy.md)。
- **AI 无结果**：在设置中检查服务地址、模型、API Key 并测试连接；AI 与本地翻译是两套功能。
- **部分软件无法取词**：桌面取词依赖目标软件能否提供文字，以及 OCR 是否能识别；可改用手动输入。
- **主窗口关闭后仍在运行**：查看 Windows 系统托盘，应用支持托盘运行。
