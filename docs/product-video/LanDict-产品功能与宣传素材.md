# LanDict 产品功能与宣传素材

整理日期：2026 年 11 月 24 日

## 产品介绍

**LanDict 是一款简洁、实用的 Windows 英语词典，把查词、翻译、阅读、生词收藏和背词复习放在一起。**

打开首页就能查询。联网时优先使用有道词典，离线时仍可使用本地词库和中英翻译；需要进一步理解单词时，可以接入自己的 AI 服务，查看例句、词根、近义词、反义词和派生词。

## 功能清单

下面的勾选框供你挑选宣传重点，未勾选不代表功能尚未实现。

### 1. 打开就能查词

- [ ] **首页直接查询**：以搜索框为中心，输入单词、短语、句子或中文即可开始查询。
- [ ] **联网优先有道**：英文单词、中文词语和有道已收录的短语，联网时优先查询有道。
- [ ] **离线仍然可用**：断网、联网查询失败或没有合适的词条时，使用本地词库；短语和句子也可以进入本地翻译。
- [ ] **词条资料集中展示**：查看词性、释义、例句、常见搭配和词形变化，具体内容以词条实际收录为准。
- [ ] **中文反查英文**：从中文词语查找对应的英文表达。
- [ ] **英美发音**：查看英美音标并播放发音；在线音频不可用时尝试系统朗读。
- [ ] **遇到生词继续查**：词典释义、例句、搭配、翻译结果和 AI 内容中的英文单词，可以点击继续查询。
- [ ] **选中文字不误跳转**：拖动选中文本时避免触发点击查词。

词典资料来源：联网查询使用有道；本地包含牛津高阶双解与 ECDICT，中文反查使用 CC-CEDICT。

### 2. 输入更顺手

- [ ] **实时释义预览**：首页和翻译页输入英文单词时，搜索框右侧可显示来自本地词库的简短释义。
- [ ] **灰色字母补全**：输入部分字母后，行内提示可能的剩余字母；按 Tab 接受，按 Esc 隐藏。
- [ ] **拼写容错**：未查到单词时尝试寻找相近拼写，并提示可能的正确单词，例如 `captuer → capture`。
- [ ] **保留查询内容**：查询后保留输入，方便修改几个字母、词尾或后缀，再次查询。
- [ ] **回车查询**：支持 Enter 提交，并处理中文输入法选字状态；翻译页长文本或多行内容使用 Ctrl+Enter。
- [ ] **最近查询浮层**：翻译页点击搜索框可查看最近 5 条查询，点击即可重新查询；重复内容自动去重，最近查的排在最前。
- [ ] **查询历史**：首页显示近期记录及释义摘要，也可进入历史页重新查询。

### 3. 离线翻译与可选 AI

- [ ] **本地中英翻译**：内置英语与简体中文之间的翻译模型，支持短语、句子和段落，离线也能使用。
- [ ] **AI 文本翻译**：英文短语和文本可提供日常表达、书面表达两个中文版本；中文文本可翻译为英文。
- [ ] **AI 中文查词**：查询中文词语时，可补充常用英文表达、用法区别和中英例句。
- [ ] **自行选择 AI 服务**：提供 DeepSeek、OpenAI 预设，也支持自定义 OpenAI 兼容接口，可填写接口地址、模型和 API Key，并测试连接。
- [ ] **按需调用或自动调用**：可以手动展开 AI 面板，也可开启查询后自动调用。
- [ ] **译文可以接着查词**：AI 返回的英文单词同样可以点击，进入相应词条继续学习。

AI 功能需要自行配置可用接口并联网，相关费用取决于所使用的服务商。整句查询目前保留“本地翻译＋可选 AI”，不提供有道整句译文。

### 4. 五个 AI 单词学习入口

查询一个英文单词后，AI 面板提供五种学习内容：

- [ ] **例句**：按不同义项组织英文例句与中文翻译，结合语境理解用法。
- [ ] **词根**：解释词根、词缀与词义之间的联系。
- [ ] **近义词**：结合具体义项说明相近单词的差别与使用场景。
- [ ] **反义词**：说明相对的含义及使用语境。
- [ ] **派生词**：查看由目标词派生、拼写不同的相关单词，以及词性、释义和例句。

派生词的展示规则区分派生关系与普通词形变化：不将过去式、复数等常规变化单独当作派生词，也不把 `water` 本身的名词／动词用法重复列为派生词。学习内容由所接入的 AI 模型生成。

### 5. 在英文阅读中积累

- [ ] **推荐阅读**：默认展示推荐内容，也可以分别浏览新闻与文章。
- [ ] **英文新闻与长文**：阅读不同来源的新闻和文章，内容不限于时政或科普。
- [ ] **手动刷新**：联网获取新的阅读内容。
- [ ] **正文点击查词**：点击英文单词，在正文旁弹出查词卡片。
- [ ] **阅读中的 AI 解释**：需要更多解释时，在查词卡片中按需调用 AI。
- [ ] **边读边收藏**：直接把遇到的单词加入生词本。
- [ ] **本篇生词集中查看**：右侧展示本篇文章中已收藏的生词。
- [ ] **全文朗读**：支持开始、暂停和继续朗读。
- [ ] **字号调整**：按自己的阅读习惯调整正文大小。
- [ ] **文章收藏与续读**：收藏文章、查看阅读历史，并从上次进度继续阅读。

当前配置的新闻来源：

- BBC News
- CGTN
- VOA
- UN News（联合国新闻）

当前配置的文章来源：

- Rest of World
- Aeon
- Quanta Magazine
- Works in Progress

新内容的获取受网络和来源网站可用性影响。

### 6. 整理自己的生词本

- [ ] **多处收藏**：从查询页、阅读查词卡片或桌面鼠标取词卡片收藏单词。
- [ ] **列表与详情分栏**：左侧浏览生词，右侧查看词条详情。
- [ ] **四种排序**：最近收藏、最早收藏、单词 A–Z、单词 Z–A。
- [ ] **搜索单词或释义**：快速找到已经收藏的内容。
- [ ] **隐藏释义自测**：先看单词回忆意思，再按需揭晓释义。
- [ ] **学习状态管理**：按待学习、学习中、已掌握筛选和调整状态。
- [ ] **批量导入**：支持粘贴单词列表，或导入 TXT、CSV、JSON，自动跳过重复词。
- [ ] **移除与撤销**：移除不需要的单词，并可在操作后撤销。
- [ ] **收藏后继续背**：自己的生词本也能作为背词来源。

### 7. 背单词与间隔复习

- [ ] **常见考试词库**：高考、四级、六级、考研、雅思、托福、GRE。
- [ ] **生活高频词**：适合日常英语积累的词表。
- [ ] **词组学习**：支持固定习语、常见搭配和多词词条。
- [ ] **背自己的生词本**：把自己收藏的词放入同一套学习流程。
- [ ] **设置每天的新词量**：可选 10、20、30、50 个。
- [ ] **新学与复习分开进入**：既能学习新词，也能复习到期和积压的单词。
- [ ] **按掌握情况安排复习**：根据“认识、不确定、不认识”调整记忆档位；不熟悉的词会在本轮再次出现。
- [ ] **方向键完成主要操作**：判断、收藏、前进和回退都可以通过键盘完成。
- [ ] **保存学习进度与本轮小结**：查看本轮作答情况，后续接着学。

当前采用七档间隔复习，间隔为 **1、3、7、16、35、75、180 天**。对外可表述为“根据掌握情况安排间隔复习”。

#### 背词键盘操作

只显示单词、尚未判断时：

- ↑：加入生词本。
- ←：不认识。
- ↓：不确定。
- →：认识。

展开释义后：

- ←：重新作答。
- ↓：改判为不认识。
- →：下一个单词。

其他操作：

- 双击 ←：返回上一个单词。
- 双击 →：不再出现。
- 空格：重复发音。
- Esc：退出当前学习界面。

### 8. 配合电脑上的使用习惯

- [ ] **桌面鼠标取词**：鼠标在可识别的英文单词上停留后显示释义，也可以发音和收藏。
- [ ] **自定义触发时间**：可设置鼠标停留多久后取词，范围为 100–3000 毫秒。
- [ ] **本地 OCR 补充**：无法直接读取文字时，尝试识别鼠标附近的英文内容。
- [ ] **三种主题**：轻盈绿、慕夜黑、晴空蓝。
- [ ] **英美朗读口音**：按个人习惯选择。
- [ ] **开机自启与托盘运行**：可设置登录 Windows 后自动启动；关闭主窗口后仍可在托盘运行。
- [ ] **无需注册登录**：生词、学习进度和设置保存在本机，目前没有云端学习数据同步。

## 宣传时保留的事实边界

- **平台**：目前提供 Windows 版本，开发环境为 Windows 11；Windows 10 兼容性尚未验证。
- **数据与联网**：本机保存生词、设置及学习进度；联网查词、阅读内容获取、部分发音和 AI 请求会访问对应的外部服务，不使用“完全不联网”或“零泄露风险”的表述。
- **适用范围**：鼠标取词依赖文字是否可读取或识别，不承诺所有软件和所有文字都能取词。
- **产品范围**：本文介绍 Windows 桌面软件，不包含独立浏览器插件的功能。
