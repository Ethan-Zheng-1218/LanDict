# LanDict 视频功能取舍清单

核对日期：2026-11-12 · 当前源码版本：0.1.3

用途：你在右侧实操并现场讲解，左侧展示精简文字。本文供你选择内容，对应的观众展示稿见 [left-panel-copy.md](left-panel-copy.md)。

按可讲解的内容整理为 **6 组、49 个候选讲解点**。这是文案拆分数量，部分入口与功能相互关联，不代表 49 个互不重复的独立模块。勾选表示“准备在视频中介绍”，未勾选不代表尚未实现。

依据当前页面入口和实现核对，未重新实测所有功能、外部阅读源和 Windows 10 兼容性。未接入当前可见界面的代码不算已交付功能。

## A. 首页与单词查询（12 项）

- [ ] **A01 · 打开就查词**：首页以搜索框为核心，输入后进入翻译／查询结果页。
- [ ] **A02 · 联网查询与离线回退【本次补充】**：英文单词与中文查词均优先查询有道；断网、请求失败或没有可用结果时回退本地词库，结果区统一显示“词库解释”。中文查询也提供独立的 AI 面板。
- [ ] **A03 · 词条资料**：展示词性、释义、例句、搭配和词形变化；具体内容以该词条及来源实际提供的数据为准。支持词形还原及中文反查。
- [ ] **A04 · 英美发音**：查看英美音标并点击播放发音。部分音频、音标通过联网获取，音频播放失败时尝试系统语音。
- [ ] **A05 · 实时释义预览【本次补充】**：首页和翻译页输入英文单词时，在搜索框右侧显示灰色短释义。来自本地精确查询，不调用 AI；未命中则不显示。
- [ ] **A06 · 灰色字母补全【本次补充】**：输入英文前缀后，行内显示本地候选词的剩余字母。Tab 接受，Esc 隐藏；候选词不保证是用户心中想查的词。
- [ ] **A07 · 拼写容错【本次补充】**：查不到时尝试本地拼写候选。只有一个有效候选时显示其解释并提示可能拼错；有多个候选时提供选择。例如 `captuer → capture`，录制前仍需用实际词库确认结果。
- [ ] **A08 · 保留搜索内容【本次补充】**：提交后，翻译页保留输入，可以直接修改字母或后缀再查；同词也能重新提交查询。
- [ ] **A09 · 最近查询浮层【本次补充】**：翻译页点击或聚焦搜索框可查看最近 5 条记录，点击直接查询。相同内容自动去重，再查时移到最前；目前没有手动固定置顶按钮。输入新内容时浮层收起。
- [ ] **A10 · Enter 查询【本次补充】**：回车提交查询，并处理中文输入法选字状态。翻译页长文本或多行输入使用 Ctrl+Enter，Shift+Enter 可换行。
- [ ] **A11 · 词典正文点击查词【本次补充】**：点击词条释义、例句、搭配、词形中的英文单词继续查询。拖动选中文本时避免误触发；不泛指界面上所有英文都能点击。
- [ ] **A12 · 查询历史**：首页显示近期查询及释义摘要；历史页按今天、昨天、之前分组，可重新查询和清除记录。当前最多保存 30 条。

## B. 本地翻译与 AI 辅助（5 项）

- [ ] **B01 · 本地中英翻译**：桌面版内置模型，支持英语与简体中文之间的短语、句子、段落翻译，可离线使用。
- [ ] **B02 · AI 单词解释**：在词典释义之外，补充用法、常见搭配及中英例句。需要自己配置可用的 AI 接口并联网。
- [ ] **B03 · AI 文本翻译**：英文文本可提供日常表达和书面表达版本；中文文本可译为英文。阅读场景的请求有不同输出要求，不承诺所有入口都显示两种版本。
- [ ] **B04 · 自选 AI 服务**：提供 DeepSeek、OpenAI 预设，以及自定义 OpenAI 兼容接口；自定义地址、模型和 API Key，并支持保存配置、测试连接。不是所有协议的 API 都能接入。
- [ ] **B05 · AI 手动或自动调用**：查询页可手动展开 AI 面板，或开启自动展开与调用。AI 是可选补充，不是只有本地查不到时才触发。

## C. 英文阅读（9 项）

- [ ] **C01 · 推荐、新闻与文章**：默认进入推荐，聚合新闻和文章；也可分别浏览新闻与文章列表。
- [ ] **C02 · 手动刷新**：刷新阅读内容，部分来源不可用时有相应提示；获取新内容需要联网。
- [ ] **C03 · 正文点击查词**：点击阅读正文中的英文单词弹出查词卡片，可查看释义、英美发音及已有的例句、搭配和词形。
- [ ] **C04 · 阅读中的 AI 解释**：展开查词卡片的“AI 解释”，按需请求补充说明，需要已配置的接口和网络。
- [ ] **C05 · 本篇生词集中管理**：在查词卡片收藏生词，右侧集中展示本篇已收藏的词，可移除或打开完整生词本。
- [ ] **C06 · 阅读字号调整**：通过阅读工具栏调整字号。
- [ ] **C07 · 全文朗读**：支持开始、暂停和继续朗读；实际音色与可用性受系统／运行环境影响。
- [ ] **C08 · 文章收藏**：收藏文章，并在收藏列表中重新打开。
- [ ] **C09 · 阅读记录与续读**：记录进度和历史，在推荐中的“继续阅读”或阅读历史中接着读。

文章：**Rest of World、Aeon、Quanta Magazine、Works in Progress**。

## D. 生词本（9 项）

- [ ] **D01 · 收藏生词**：从查询页、阅读查词卡片或鼠标取词卡片收藏到本地生词本。
- [ ] **D02 · 左侧列表、右侧详情**：选择单词后查看释义、音标、发音、来源，以及已有的例句和搭配。
- [ ] **D03 · 四种排序**：最近收藏、最早收藏、单词 A–Z、单词 Z–A。
- [ ] **D04 · 搜索生词**：按单词或释义查找收藏内容。
- [ ] **D05 · 隐藏释义自测**：隐藏释义后快速回忆，也可以逐词点击揭晓。
- [ ] **D06 · 学习状态管理**：按待学习、学习中、已掌握筛选，并在词条详情中手动调整状态。
- [ ] **D07 · 批量导入**：支持粘贴单词列表，或导入 TXT、CSV、JSON；自动跳过重复词。文件不超过 5 MB，不直接导入 XLSX。
- [ ] **D08 · 移除与撤销**：移除不需要的生词，并可通过操作后的提示撤销移除。
- [ ] **D09 · 接着背词**：从生词本进入背单词模块，选择“我的生词本”作为学习内容。

### 可用于演示的导入内容

TXT：

```text
capture
curiosity
practical
```

CSV：

```csv
word,meaning
capture,捕获
curiosity,好奇心
practical,实用的
```

JSON：

```json
[
  { "word": "capture", "meaning": "捕获" },
  { "word": "curiosity", "meaning": "好奇心" }
]
```

没有释义也可以导入，先显示“待补充释义”；打开词条时尝试查询补充资料。

## E. 背单词与复习（7 项）

- [ ] **E01 · 常见词库**：高考、四级、六级、考研、雅思、托福、GRE、生活高频。
- [ ] **E02 · 词组学习**：固定习语、常见搭配、多词词条。
- [ ] **E03 · 背自己的生词本**：收藏的词也可使用同一套学习和复习流程。
- [ ] **E04 · 设置新词数量**：每天背的新词量可选 10、20、30、50；分别提供背新单词和复习入口，不宣传尚未实现的任意任务编排或提醒。
- [ ] **E05 · 分级间隔复习**：依据认识、不确定、不认识调整记忆档位；不熟悉的词在本轮再次出现，到期及积压词进入复习队列。
- [ ] **E06 · 方向键操作**：用方向键完成判断、收藏、前进和回退，空格重听发音；双击右键可标为不再出现。
- [ ] **E07 · 本轮小结与进度**：展示这一轮的作答情况，保存学习进度，可返回主页或再学一组。

### 复习方法的准确表述

当前为七档间隔复习，间隔是 **1、3、7、16、35、75、180 天**。认识升一级；不确定保持档位并缩短间隔；不认识降低档位并在本轮再考一次。

适合说：“根据掌握情况安排复习。”不直接宣称实现了某个标准化的“艾宾浩斯算法”或其他未在代码中实现的算法。

### 键盘操作备忘

只显示单词、尚未判断时：

- ↑：加入生词本。
- ←：不认识。
- ↓：不确定。
- →：认识。

展开释义后：

- ←：返回当前词重新作答。
- ↓：改判为不认识。
- →：下一个单词。

其他操作：

- 双击 ←：返回上一个单词。
- 双击 →：不再出现。
- 空格：重复发音。
- Esc：退出当前学习界面。

对外称“方向键操作”。代码额外处理数字小键盘左右键，不承诺 Num Lock 开启时数字小键盘所有方向均可用。

## 录制口径与功能边界

1. **平台**：只介绍 Windows 版本；你的开发环境是 Windows 11，Windows 10 兼容性未验证。
2. **联网策略已更新**：旧文案“查询只调用本地词库”已不符合当前实现，应改为“联网优先有道，离线回退本地”。预释义和字母补全仍来自本地词库。
3. **历史置顶**：说“最近查过的词自动排到最前”，不说有手动永久置顶功能。最近 5 条浮层在翻译页，首页当前为查询记录卡片。
4. **补全与纠错不同**：补全在输入时提示后续字母；纠错在提交且查不到时尝试找相近词。两者均不保证所有词都能命中。
5. **词库与 AI 不同**：词库查询无需绑定 AI API；AI 要配置接口并联网，不承诺免费或自动兜底。
6. **本地保存与联网不同**：数据在本机保存，但联网查词会请求有道，AI 查询会发送内容给对应服务商；阅读和部分发音也需访问外部服务。不使用“完全不上云”“零泄露风险”的表述。
7. **阅读能力**：本次只计入当前可见入口。高亮、批注、划句翻译等留存代码，以及只有界面提示而未核实持久化的读后感，不计入候选功能。
8. **旧时间预算**：清单供取舍，不是把全部内容塞进 2–3 分钟。若仍按原时长录制，宜保留少量主功能，其余作为后续补充内容。
