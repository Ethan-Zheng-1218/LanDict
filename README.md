# LanDict

最新版本：**0.1.11**（2026-11-25）。调整首页标题位置，延续生词本备份、鼠标取词和离线翻译体验的改进。详见[更新日志](docs/changelog.md)。

一款在自己电脑上使用的 Windows 英语词典，把查词、翻译、英文阅读、生词收藏和间隔复习放在一起。

[English](docs/README.en.md) · [下载 Windows 安装包](https://github.com/Ethan-Zheng-1218/LanDict/releases/latest) · [安装指南](docs/installation.md) · [使用指南](docs/usage.md)

## 主要功能

- 中英文查词：联网优先查询有道，离线使用本地词库，支持输入补全、释义预览和查询历史。
- 中英翻译：本地翻译资源准备完成后可离线翻译短语、句子和段落；也可接入自己的 AI 服务。
- AI 单词学习：按需生成例句、词根、近义词、反义词和派生词解释。
- 英文阅读：浏览新闻和文章，正文点击查词、收藏生词、朗读并保存阅读进度。
- 生词本：搜索、排序、学习状态管理，导入词表，导出和恢复完整 JSON 生词备份。
- 背词复习：考试词库、生活高频词和自己的生词本，按掌握情况安排间隔复习。
- 桌面使用：鼠标悬停取词、可选 OCR、三种主题、托盘运行和开机自启。

## 快速开始

1. 下载 [LanDict_0.1.11_x64-setup.exe](https://github.com/Ethan-Zheng-1218/LanDict/releases/download/v0.1.11/LanDict_0.1.11_x64-setup.exe)。
2. 运行安装程序，阅读使用协议并选择安装选项。
3. 打开 LanDict，在首页输入单词并按 Enter 查询。
4. 在“设置 → 关于”确认版本为 **0.1.11**。

当前提供 Windows x64 安装包，开发环境为 Windows 11；Windows 10 兼容性尚未验证。首次安装可能需要联网准备 WebView2，首次启动会在后台下载本地翻译运行环境和模型；资源准备完成后才能使用离线整句翻译。普通查词无需配置 AI。

安装包尚未代码签名，Windows 可能显示未知发布者提示。文件来源和 SHA-256 核对方法见[安装指南](docs/installation.md)。

## 数据与联网

生词、设置和学习进度保存在本机，目前没有云端学习数据同步。联网查词、阅读、在线发音、翻译资源下载及可选 AI 功能会访问对应服务。AI 需要自行填写服务地址、模型和 API Key，费用由服务商决定。

本仓库是 Windows 桌面应用；浏览器悬停词典插件为独立项目。
